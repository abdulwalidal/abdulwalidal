### 👨‍💻 About Me

I'm a **Software Engineering undergraduate (Batch '27)** who genuinely enjoys building things with code and figuring out how real-world systems come together.

My current focus is **Spring Boot** and backend development. I've been exploring **Spring Security** lately, which naturally pulled me into learning **JWT (JSON Web Tokens)** — still getting comfortable with it, but every day it clicks a little more.

I don't claim to be an expert at anything. I'm just someone who shows up, stays curious, and improves step by step.

**A few things about me:**
- 🌱 Learning something new every week — right now it's auth & security
- 🔧 I prefer understanding *why* things work, not just *how*
- 🐧 Comfortable in Linux environments
- ☁️ Dabbled in Azure for cloud basics
- 🤝 Always happy to connect with fellow learners
